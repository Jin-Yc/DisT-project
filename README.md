# DisT

DisT 是面向 NIQ 数据产品经理（PL）的产品准备度工作台原型。它通过项目总览、产品准备度引导与 PRD Review，帮助团队把不同成熟度的产品想法整理为可评审、可交付的产品方案。

## 功能

- 项目组合总览：展示项目阶段、风险、待办和甘特排期。
- 产品准备度：以结构化问题引导用户澄清客户、问题、价值主张与范围。
- PRD Review：根据产品需求文档的内容，识别证据、范围、依赖和成功标准中的待补充项。
- 项目管理页面：包含项目列表、项目详情、新建项目和设置等原型页面。

## 本地运行

这是一个无构建步骤的静态网页项目。克隆后，直接在浏览器打开 `index.html` 即可。

也可以在项目目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 项目结构

```text
assets/          样式与交互脚本
*.html           各功能页面
prd-review/      PRD Review 原型页面
dist/            静态构建产物/发布页面
idea.md          产品需求草案
```

## 说明

当前版本为前端交互原型：页面中的 AI 建议、成熟度评分和项目数据均为本地规则与模拟数据，最终结论仍需人工确认。
